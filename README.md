# daoukitservices.com

Static site for Daouk IT Services: a scroll story that follows the signal
from fiber to switch, router, firewall and server room.

- `index.html`: the page (generated from the Flask project "daoukitservices v2" on the Desktop)
- `static/`: styles, script, fonts and pictures
- `vercel.json`: tells Vercel to serve the files as they are (no build step)

The previous React site is kept on the `old-react-site` branch.
